About the Project

This website was created as a Web Technologies project about a real coffee shop in Astana. The selected organization is Zebra Coffee, located on Mangilik El Avenue, 56. The purpose of the website is to present useful information about the coffee shop, including its location, menu, and contact details. The project also demonstrates the use of basic HTML structure and semantic elements. The website contains four main pages: Home, Menu, Visit, and Colophon. Each page has a consistent navigation menu that allows visitors to move between the sections of the website. Information about the coffee shop was gathered from available public sources and personal observations. Personal photographs are used to show the actual location. During the project, different HTML elements were used to organize information clearly. Tables are used for menu prices, while lists are used to organize categories and other details. A form was also added to demonstrate different HTML form controls.

Research and Sources

Information for this website was gathered from public details about Zebra Coffee, including its location, contact details, menu items, and prices. Additional information was checked before being added to the website. Personal photographs are also used as part of the project.

  • Information about Zebra Coffee
  • Location and contact information
  • Menu and price information
  • Personal photographs

Technology Used

The website was built using HTML. The project does not use CSS, JavaScript, frameworks, templates, or site builders. HTML semantic elements are used to structure the content and give meaning to different sections of each page.

The website contains four HTML pages:

  1. index.html
  2. menu.html
  3. visit.html
  4. colophon.html

Project Reflection

The project helped me understand how a basic website is structured using HTML. I learned how to organize content with headings, paragraphs, lists, tables, and semantic elements. Creating several linked pages also helped me understand relative links and website navigation. One of the important parts of the project was gathering real information and arranging it into a clear website structure. The project also showed how forms can be built with different input types and labels. Working without CSS made it easier to concentrate on HTML structure and semantic meaning.
